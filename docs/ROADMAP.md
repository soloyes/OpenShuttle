# Roadmap

Подробности и обоснования в [VISION.md](VISION.md). Каждый этап делается в своей ветке и вливается в `main`, после чего сайт обновляется автоматически.

Арт делается кодом: шейдеры, частицы, процедурные фоны, HUD и иконки, нарисованные программно.

## Этап 0. Стабильность (`fix/stability`)
- [x] Ограничить dt, ставить на паузу при скрытой вкладке (баги 1, 2)
- [x] Сброс состояния между играми: множители экипажа, лазер, счётчики, ракеты, Death Mode (3, 4, 7, 13, 14)
- [x] Пул аномалий: уровень и время жизни (6)
- [x] Орбита чёрной дыры внутри карты (5)
- [x] Ресурсы: FBO и ShapeRenderer освобождаются, FBO RGBA8888 и пересоздаётся при resize (8, 16)
- [x] Null-проверка шейдера паузы, логирование ошибок компиляции шейдеров (9)
- [x] Телепорт из чёрной дыры, жизни после game over (10, 11)
- [x] Обломки астероидов, очки за аномалию, строка результатов (12, 15, 17)
- [x] Параллакс от dt, скрыть Exit в браузере (16)
- [x] Шрифты Linear, mipmap для атласа
- [x] Громкость музыки не трогает эффекты; метки киллспри; `lowp` в шейдере

## Этап 1. Под ТВ (`feature/tv`)
- [x] Камера ближе в ландшафте (zoom 0.6, видимая площадь как в исходном портретном дизайне), карта считается от видимой области
- [x] Безопасная зона для HUD, полоски толще
- [x] Убрать тач-наследие: боковые переключатели скрыты, рука заменена подсказкой по управлению
- [x] ЭМИ-импульс (Y / F) вместо тапа по аномалии
- [x] Видимая граница сектора, камера не теряет корабль за краем
- [x] Камера с упреждением по скорости и плавным догоном
- Перенесено в этап 2: новый HUD целиком, меню с навигацией фокусом, ширинная вёрстка экранов

## Этап 2. Картинка (`feature/visuals`)
- [ ] Новый HUD: телеметрия в одном стиле, программно нарисованные иконки, подсказки кнопок
- [x] Новое главное меню: пилоты, журнал полётов, кодекс, настройки, об игре; навигация фокусом (крестовина/стик, A/B, клавиатура, тач); ландшафт и портрет
- [x] Пауза и отчёт о полёте в новом стиле
- [x] Процедурный фон: слои туманностей в шейдере, звёзды с параллаксом и палитрой
- [x] Bloom, виньетка, зерно, обесцвечивание на паузе (цветокоррекция по сектору — в этапе 3)
- [ ] Частицы: разные текстуры (искры, дым, вспышки), трейл двигателя
- [ ] Лазер и лучи текстурными лучами вместо цепочки точек, кольца вместо линий ShapeRenderer
- [x] Чёрная дыра в духе Gargantua: тень, кольцо фотонов, линза Эйнштейна, наклонный диск с доплеровским усилением и кеплеровской турбулентностью, линзированная дуга дальней стороны
- [x] Затягивание: захваченные объекты осыпаются раскалённым «песком» по кеплеровским орбитам, линза его размазывает
- [x] Хитстоп и вспышки экрана при уроне, потере жизни, убийствах

## Этап 3. Структура и баланс (`feature/sectors`)
- [ ] 19 секторов: цели, таблицы спавна, палитра
- [ ] Экстракция и победа, аркадный режим отдельно
- [ ] Боссы и сет-пьесы: электрическая аномалия, шторм астероидов, коллапс разрыва
- [ ] Ребаланс: радиация, топливо, жизни, баф экипажа
- [ ] Обучение в первом секторе

## Этап 4. Лор и мета (`feature/story`)
- [ ] Именной экипаж, бортжурналы, кодекс
- [ ] Радиоперехваты между секторами, интро и концовки
- [ ] Прогресс между забегами, достижения
- [ ] RU/EN

- [ ] Питч-вариации и стерео-панорама SFX
- [ ] Адаптивная музыка (слои)
